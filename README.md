# TR1 Apps

Public landing pages for TR1.eu's apps, served with GitHub Pages.

- `index.html`: product directory
- one `<product>.html` page per app: Smartlate, GrabScreen, TwoTrack, GrabDab, ShotSync, AlefBet!, HubContact, TabLabler, Filternizer, EchoLingo, Live Call Translator

Plain static HTML with no build step. Fonts load from Google Fonts.
